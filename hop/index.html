Envoyer des fichiers iPhone vers PC ou Android, par navigateur

Le scénario est banal : tu veux récupérer une photo sur ton PC pour terminer un document. Ou passer un PDF à quelqu’un qui utilise Android. Te l’envoyer par mail fonctionne parfois, mais cela ajoute une boîte de réception au milieu d’un échange entre deux appareils posés sur la même table. Hop propose un trajet local, sur ton Wi-Fi.

Le principe tient en quelques gestes. Tu lances Hop sur l’iPhone. Sur le PC, tu ouvres ton navigateur et tu saisis l’adresse affichée par l’app. Sur Android, tu peux scanner le QR code. Tu entres ensuite le code à quatre chiffres. Aucun logiciel à installer sur l’autre appareil, aucun compte à créer.

  1. Connecte les deux appareils au même Wi-Fi.
  2. Lance Hop et ouvre l’adresse indiquée dans le navigateur de l’autre appareil, ou scanne le QR code sur Android.
  3. Saisis le code à quatre chiffres, puis choisis les fichiers à envoyer.

Tes photos sur Windows, tes vidéos en pleine qualité

Une photo arrivée sur l’ordinateur mais impossible à ouvrir, c’est une victoire un peu courte. Hop convertit les photos d’iPhone en JPEG pendant le transfert pour que Windows puisse les ouvrir. Tu peux ainsi récupérer une image pour un document ou la transmettre ensuite depuis ton PC.

Les vidéos sont envoyées en pleine qualité, sans compression et sans limite de taille. La description de Hop distingue bien les deux : les photos passent en JPEG, les vidéos conservent leur qualité. Si ton objectif est de déplacer des photos, le guide transférer des photos iPhone vers PC sans câble détaille la préparation et les vérifications utiles.

Le retour vers l’iPhone est prévu aussi

Le transfert fonctionne dans les deux sens. Pour récupérer un fichier du PC sur ton iPhone, tu le déposes sur la page ouverte dans le navigateur. Les fichiers reçus arrivent dans l’app Fichiers. Tu peux ensuite les partager ou enregistrer les images dans Photos.

Hop permet aussi d’échanger du texte, avec un bouton Copier. Une adresse à récupérer sur le téléphone, un lien à ouvrir sur l’ordinateur, un code à transmettre : ces petits morceaux de texte ont eux aussi le droit de voyager. Tu évites de retaper une adresse interminable en surveillant chaque caractère.

Un échange sur ton Wi-Fi, sans détour par le cloud

Les échanges restent sur ton réseau Wi-Fi. Hop ne demande pas de compte et n’envoie pas tes fichiers dans le cloud. L’app ne comporte ni publicité ni pistage. Un nouveau code est généré à chaque session, et le navigateur doit le fournir pour se connecter.

Pas de Wi-Fi à disposition ? Tu peux activer le partage de connexion de l’iPhone et connecter le PC dessus. Le navigateur sert toujours de point d’entrée. Hop fonctionne également avec un Chromebook, une tablette ou un Mac doté d’un navigateur : le PC Windows et le téléphone Android ne sont pas les seuls destinataires possibles.

Questions fréquentes

Faut-il installer Hop sur le PC ou le téléphone Android ?

Non, l’autre appareil utilise son navigateur. Tu ouvres l’adresse affichée par Hop, ou tu scannes le QR code avec Android, puis tu saisis le code à quatre chiffres.

Peut-on envoyer un fichier du PC vers l’iPhone ?

Oui, tu peux déposer un fichier sur la page ouverte dans le navigateur pour l’envoyer à l’iPhone. Les fichiers reçus arrivent dans l’app Fichiers, prêts à être partagés ou enregistrés dans Photos selon leur contenu.

Hop utilise-t-il le cloud pour les transferts ?

Non, les transferts restent sur ton Wi-Fi. Aucun compte n’est nécessaire et l’app ne comporte ni publicité ni pistage.
